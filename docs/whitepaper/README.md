# White Paper

The original project was documented as **Networked Player Piano Requirements & Architecture White Paper v1.1** during the design exploration that became OpenOrchestrion.

The repository Markdown documents are now the living specification and include later refinements such as the OpenOrchestrion name and AI Music Concierge.

The historical white paper covers the Raspberry Pi appliance model, local web control, MIDI playback, music-library architecture, Google Drive/off-device backup, recovery, reference hardware thinking, multi-instrument playback, and multi-device expansion.

A future publication pass should regenerate the white paper under the OpenOrchestrion name from the living requirements in this repository so the binary document and Markdown specification remain aligned.
