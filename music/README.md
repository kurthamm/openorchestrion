# Music Directory

The public repository intentionally does **not** contain a large general-purpose MIDI collection.

Only music with clearly documented redistribution rights should be committed here. Every included work should have provenance and license metadata.

Personal or commercially licensed MIDI belongs in the user's local library and is excluded from source control.

Potential open-library sources to evaluate include public-domain and appropriately licensed material from projects such as Mutopia and Wikimedia Commons. Dataset-specific licenses must be reviewed before redistribution.

The OpenOrchestrion importer will eventually support bringing personal MIDI into the local appliance without placing those files in GitHub.
